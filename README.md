# # About  
Wterminal is a WhatsApp Terminal Edition.

# # Architecture

**\* Backend : ** Node.js avec `@whiskeysockets/baileys` qui tourne en arrière-plan.
**\* Frontend : ** Interface TUI (Terminal User Interface) connectée via WebSockets.

# # Programming languages
1. Python for the frontend
2. NodeJS for the backend

# # Module installation
1. For the backend
- npm install @whiskeysockets/baileys ws pino

2. For the frontend
- pip install websockets qrcode colorama pillow

# # Installation & Lancement

1. Clone the repository.
2. Configure backend : `cd backend && npm install`.
3. Launch the server et scan the QR Code : `node server.js`.
4. Run wterminal on a new terminal `python app.py`.
